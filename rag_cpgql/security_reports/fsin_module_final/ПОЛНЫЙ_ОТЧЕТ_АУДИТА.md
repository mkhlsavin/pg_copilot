## ЧАСТЬ 2: КРИТИЧЕСКИЕ УЯЗВИМОСТИ (CRITICAL)

### 2.1 SECRET_KEY с небезопасным значением по умолчанию

**ID:** FILE_SECRET_FALLBACK_001
**CWE:** [CWE-798](https://cwe.mitre.org/data/definitions/798.html)
**Файл:** `backend/settings.py:25`
**Severity Score:** 9.0/10

**Уязвимый код:**
```python
SECRET_KEY = os.environ.get('SECRET_KEY', 'wekgh2o35b24uk5g23yuf23yu5g23tb2j4bt')
```

**Описание:**
SECRET_KEY используется Django для криптографических операций (CSRF токены, подписи сессий, подписи cookies). Если переменная окружения не установлена, используется захардкоженное значение, что приводит к:
- Возможности подделки CSRF токенов
- Компрометации сессий пользователей
- Возможности дешифровки данных

**Рекомендация:**
```python
# Вариант 1: Требовать переменную окружения
SECRET_KEY = os.environ['SECRET_KEY']

# Вариант 2: Генерация при первом запуске
from django.core.management.utils import get_random_secret_key
SECRET_KEY = os.environ.get('SECRET_KEY') or get_random_secret_key()
```

### 2.2 DEBUG=True по умолчанию

**ID:** FILE_DJANGO_DEBUG_001
**CWE:** [CWE-489](https://cwe.mitre.org/data/definitions/489.html)
**Файл:** `backend/settings.py:28`
**Severity Score:** 9.0/10

**Уязвимый код:**
```python
DEBUG = os.environ.get('DEBUG', True)
```

DEBUG=True в продакшене приводит к:

- Раскрытию настроек приложения

**Рекомендация:**
```python
# Безопасный вариант
DEBUG = os.environ.get('DEBUG', 'False').lower() in ('true', '1', 'yes')
```

## ЧАСТЬ 3: УЯЗВИМОСТИ ВЫСОКОЙ КРИТИЧНОСТИ (HIGH)

### 3.1 Permission Check на основе DEBUG

**ID:** FILE_DEBUG_PERM_001
**CWE:** CWE-489, CWE-306
**Файл:** `backend/permissions.py:11`

**Уязвимый код:**
```python
return settings.DEBUG
```

**Описание:**
Использование DEBUG в качестве условия для проверки прав доступа - критическая ошибка. В режиме разработки все проверки будут пройдены, а в продакшене - заблокированы.

**Рекомендация:**
Использовать Role-Based Access Control (RBAC):
```python
return request.user.is_authenticated and request.user.has_perm('can_access_debug_api')
```

### 3.2 CORS Allow All Origins

**ID:** FILE_CORS_001
**CWE:** [CWE-346](https://cwe.mitre.org/data/definitions/346.html)
**Файл:** `backend/settings.py:30`

**Уязвимый код:**
```python
CORS_ALLOW_ALL_ORIGINS = True
```

**Описание:**
Разрешает кросс-доменные запросы с любого источника, что позволяет:
- CSRF атаки с вредоносных сайтов
- Утечку данных через JavaScript

**Рекомендация:**
```python
CORS_ALLOW_ALL_ORIGINS = False
CORS_ALLOWED_ORIGINS = [
    "https://your-frontend.com",
    "https://admin.your-frontend.com",
]
```

### 3.3 ALLOWED_HOSTS Wildcard

**ID:** FILE_HOSTS_001
**CWE:** [CWE-942](https://cwe.mitre.org/data/definitions/942.html)
**Файл:** `backend/settings.py:32`

**Уязвимый код:**
```python
ALLOWED_HOSTS = json.loads(os.environ.get('ALLOWED_HOSTS', '["*"]'))
```

**Описание:**
Wildcard в ALLOWED_HOSTS позволяет:
- Host Header Injection атаки
- Cache Poisoning
- Password Reset Poisoning

**Рекомендация:**
```python
ALLOWED_HOSTS = json.loads(os.environ.get('ALLOWED_HOSTS', '[]'))
if not ALLOWED_HOSTS:
    raise ImproperlyConfigured("ALLOWED_HOSTS must be set")
```

### 3.5 JWT Long Expiry (7 дней)

**ID:** FILE_JWT_001
**CWE:** [CWE-613](https://cwe.mitre.org/data/definitions/613.html)
**Файл:** `backend/settings.py:184`

**Уязвимый код:**
```python
"ACCESS_TOKEN_LIFETIME": timedelta(days=7),
```

**Описание:**
Access Token с временем жизни 7 дней - критически долго. При компрометации токена злоумышленник имеет доступ на неделю.

**Рекомендация:**

```python
"ACCESS_TOKEN_LIFETIME": timedelta(minutes=15),  # Короткоживущий

```

### 3.6 Path Traversal (os.remove)

**ID:** FILE_PATH_001 / CPG_FILE_OP_001
**CWE:** [CWE-22](https://cwe.mitre.org/data/definitions/22.html)
**Файл:** `person/views.py:174`

**Уязвимый код:**
```python
os.remove(os.path.join(settings.MEDIA_ROOT, photo.name))
```

**Описание:**
Если `photo.name` содержит `../../../etc/passwd`, может произойти удаление произвольного файла.

**Рекомендация:**
```python
import os

def safe_remove_media(photo_name):
    full_path = os.path.realpath(os.path.join(settings.MEDIA_ROOT, photo_name))
    media_root = os.path.realpath(settings.MEDIA_ROOT)

    if not full_path.startswith(media_root):
        raise ValueError("Path traversal attempt detected")

    if os.path.exists(full_path):
        os.remove(full_path)
```

### 4.2 Большой PAGE_SIZE (DoS risk)

**ID:** FILE_PAGESIZE_001
**CWE:** CWE-400, CWE-770
**Файл:** `backend/settings.py:176`

**Уязвимый код:**
```python
'PAGE_SIZE': 10000,
```

**Описание:**
PAGE_SIZE = 10000 позволяет запросить 10000 записей одним запросом, что может привести к:
- Исчерпанию памяти сервера
- Медленным ответам
- DoS атакам

**Рекомендация:**
```python
REST_FRAMEWORK = {
    'PAGE_SIZE': 20,
    'MAX_PAGE_SIZE': 100,
}
```
