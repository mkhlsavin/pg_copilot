# Refactoring Module

Refactoring assistance including code smell detection and automated refactoring suggestions.

## Overview

```
src/refactoring/
├── detector.py          # Code smell detector
├── suggestions.py       # Refactoring suggestions
├── patterns/            # Refactoring patterns
└── __init__.py
```

## Features

- Code smell detection
- Duplicate code identification
- Dead code detection
- Refactoring suggestions
- Mass refactoring support
