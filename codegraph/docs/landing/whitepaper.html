1. Резюме

CodeGraph — система анализа кода на базе GigaChat, использующая гибридный поиск (граф кода + векторные эмбеддинги) для мгновенного ответа на вопросы разработчиков о кодовой базе.

Разработчики тратят 60% времени на понимание существующего кода. CodeGraph сокращает это время в 10-600 раз благодаря интеллектуальному анализу на базе GigaChat.

<5 сек Ответ на вопрос
+33.6% Точность vs baseline

3. Решение CodeGraph

CodeGraph объединяет три ключевые технологии для решения этих проблем:

Ключевые компоненты

  • GigaChat — понимание intent пользователя и генерация ответов на естественном языке
  • Code Property Graph (CPG) — структурный анализ кода с DuckDB
  • Hybrid Retrieval — комбинация векторного и графового поиска

Что предоставляет CodeGraph

  1. Интерактивный AI-ассистент — отвечает на вопросы о коде за 2-3 секунды
  2. Автоматический поиск уязвимостей — 12+ типов (SQL injection, buffer overflow, etc.)
  3. 16 готовых сценариев — от онбординга до security incident response
  4. Автогенерация документации — API docs, архитектурные диаграммы
  5. Code review automation — анализ PR/MR с рекомендациями
