## СЛАЙД 4: Как работает GigaChat

```
╔══════════════════════════════════════════════════════════════════╗
║               КАК РАБОТАЕТ GIGACHAT В СИСТЕМЕ                    ║
╠══════════════════════════════════════════════════════════════════╣
║                                                                  ║
║     Вопрос                                                       ║
║        │                                                         ║
║        ▼                                                         ║
║  ┌─────────────┐   ┌──────────────┐   ┌─────────────────┐        ║
║  │  ANALYZER   │─▶ │  ENRICHMENT │──▶│   GENERATOR     │        ║
║  │  GigaChat   │   │  GigaChat    │   │   GigaChat      │        ║
║  │             │   │              │   │                 │        ║
║  │ Понимает    │   │ Добавляет    │   │ Генерирует      │        ║
║  │ intent      │   │ контекст     │   │ SQL запрос      │        ║
║  └─────────────┘   └──────────────┘   └─────────────────┘        ║
║                                              │                   ║
║                                              ▼                   ║
║                    ┌─────────────────────────────────────┐       ║
║                    │          INTERPRETER                │       ║
║                    │            GigaChat                 │       ║
║                    │                                     │       ║
║                    │  Синтезирует ответ на русском языке │       ║
║                    │  с рекомендациями по исправлению    │       ║
║                    └─────────────────────────────────────┘       ║
║                                                                  ║
║  4-5 вызовов GigaChat на один пользовательский вопрос            ║
╚══════════════════════════════════════════════════════════════════╝
```

**Спикерноты:**
> "GigaChat используется на каждом этапе обработки:
> - Analyzer понимает, что хочет пользователь
> - Enrichment добавляет domain-specific контекст
> - Generator создаёт запрос к графу кода
> - Interpreter формирует понятный ответ
>
> Итого 4-5 вызовов API на вопрос."
