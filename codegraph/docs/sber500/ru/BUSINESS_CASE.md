## 1. О ПРОДУКТЕ

### Одно предложение
**CodeGraph** — система анализа кода на базе GigaChat, использующая гибридный поиск (граф кода + векторные эмбеддинги) для мгновенного ответа на вопросы разработчиков о кодовой базе.

### Проблема

| Боль | Масштаб | Источник |
|------|---------|----------|
| Разработчики тратят **60% времени** на понимание существующего кода | GitHub Survey 2023 | Ежегодное исследование 90,000 разработчиков |
| Ручной code review пропускает **до 80% уязвимостей** | NIST Report | Анализ 100+ enterprise проектов |
| Онбординг новых сотрудников занимает **3-6 месяцев** в enterprise | Industry Average | Опросы CTO крупных компаний |
| Документация устаревает в течение **2-4 недель** после изменений | Developer Survey | Исследование 500+ команд |

### Решение

CodeGraph предоставляет:

1. **Интерактивный AI-ассистент** — отвечает на вопросы о коде за 2-3 секунды
2. **Автоматический поиск уязвимостей** — 12+ типов (SQL injection, buffer overflow, etc.)
3. **16 готовых сценариев** — от онбординга до security incident response
4. **Автогенерация документации** — API docs, архитектурные диаграммы
5. **Code review automation** — анализ PR/MR с рекомендациями

### Технические детали

**Конфигурация:**
```yaml
llm:
  provider: "gigachat"
  gigachat:
    model: "GigaChat-2-Pro"
    credentials: ${GIGACHAT_AUTH_KEY}
    scope: "GIGACHAT_API_PERS"
    timeout: 60
    temperature: 0.7
    max_tokens: 2000
```

**Поддерживаемые модели:**
- GigaChat-2 — быстрый, для development
- GigaChat-2-Pro — основной, production
- GigaChat-2-Max — максимальное качество

**Количество вызовов GigaChat на запрос:**
| Агент | Вызовов | Назначение |
|-------|---------|------------|
| Analyzer | 1 | Классификация intent |
| Enrichment | 1-2 | Обогащение контекста |
| Generator | 1 | Генерация запроса |
| Interpreter | 1 | Синтез ответа |
| **Итого** | **4-5** | На один пользовательский вопрос |

### Почему GigaChat критичен

| Функция | Без GigaChat | С GigaChat |
|---------|--------------|------------|
| Понимание вопроса | Keyword matching | Семантическое понимание intent |
| Генерация запросов | Жёсткие шаблоны | Динамическая генерация SQL |
| Ответы пользователю | Сырые данные | Natural language + рекомендации |
| Многоязычность | Только EN | RU + EN нативно |
| Domain adaptation | Фиксированные паттерны | Контекстное обогащение |

**Ключевые преимущества GigaChat:**
- Нативная поддержка русского языка для российских enterprise
- Данные не покидают российскую юрисдикцию (compliance)
- Высокое качество понимания технического контекста

### 6.2 Контроль доступа (RBAC)

```
ADMIN (полный доступ)
  └── REVIEWER (code review + analyst)
        └── ANALYST (выполнение + управление сессиями)
              └── VIEWER (только чтение)
```

**21 гранулярное разрешение:**
- Сценарии: чтение, выполнение
- Запросы: выполнение, валидация
- Ревью: выполнение, GitHub, GitLab
- Сессии: чтение, запись, удаление
- Пользователи: управление
- API-ключи: управление

### 6.3 Data Loss Prevention (DLP)

**Защита при работе с LLM:**
```
User Query ──► [DLP Scanner] ──► GigaChat ──► [DLP Scanner] ──► Response
                    │                              │
                    ▼                              ▼
              Block/Mask/Log                 Mask Sensitive Data
```

**25+ паттернов обнаружения:**
- **Credentials (критический):** AWS ключи, GitHub токены, приватные ключи, пароли
- **PII (высокий):** Email, телефоны, паспорта, номера карт
- **Source Code (средний):** Connection strings, внутренние пути
